# Customer Churn Prediction

A machine learning project that predicts whether a telecom customer is likely to churn using Logistic Regression and a Streamlit web application.

## Project Overview

Customer churn occurs when a customer stops using a company's services.

In this project, a machine learning model is trained on telecom customer data to predict whether a customer is likely to churn based on factors such as:

* Customer demographics
* Tenure
* Internet and phone services
* Contract type
* Payment method
* Monthly charges
* Total charges

The project covers the complete machine learning workflow, from data exploration and preprocessing to model training, evaluation, model saving, and deployment through a Streamlit application.
## Dataset

The project uses the **Telco Customer Churn** dataset.

The dataset contains **7,043 customer records** and includes information about:

* Customer demographics
* Services used
* Contract information
* Payment methods
* Monthly charges
* Total charges
* Customer churn status

### Target Variable

The target variable is:

* `Churn = Yes` → Customer churned
* `Churn = No` → Customer did not churn
## Machine Learning Workflow

The project follows these main steps:

1. **Data Loading** — Load the telecom customer dataset using Pandas.
2. **Data Understanding** — Examine columns, data types, missing values, and basic statistics.
3. **Data Cleaning** — Convert `TotalCharges` to numeric format and handle missing values.
4. **Exploratory Data Analysis** — Analyze churn distribution and relationships between churn and customer characteristics.
5. **Feature Preparation** — Separate features and the target variable.
6. **Train-Test Split** — Split the data into training and testing sets.
7. **Categorical Encoding** — Convert categorical features into numerical form using OneHotEncoder.
8. **Feature Scaling** — Standardize numerical features using StandardScaler.
9. **Model Training** — Train a Logistic Regression model.
10. **Model Evaluation** — Evaluate the model using accuracy, precision, recall, and F1 score.
11. **Prediction Probability** — Generate the estimated probability of customer churn.
12. **Model Saving** — Save the trained model and preprocessing pipeline using Joblib.
13. **Web Application** — Build an interactive prediction application using Streamlit.
## Model Performance

The project uses **Logistic Regression** as the classification model.

The model was evaluated on the test dataset using several classification metrics:

| Metric    |  Score |
| --------- | -----: |
| Accuracy  | 80.55% |
| Precision | 65.72% |
| Recall    | 55.88% |
| F1 Score  | 60.40% |

These results represent the performance of the model on the held-out test data.

The model also produces a **churn probability**, which provides an estimated likelihood of churn for an individual customer.
## Streamlit Web Application

The trained machine learning model is integrated into a Streamlit web application.

The application allows users to enter customer information such as:

* Customer demographics
* Tenure
* Services
* Contract type
* Payment method
* Monthly charges
* Total charges

After clicking **Predict Churn**, the application displays:

* Churn prediction
* Estimated churn probability
* A simple interpretation of the probability

The application also includes information about the machine learning model and its performance.

## How to Run the Project

### 1. Clone the Repository

```powershell
git clone https://github.com/Bose0023/customer-churn-prediction.git
cd customer-churn-prediction
```

### 2. Create a Virtual Environment

```powershell
python -m venv venv
```

### 3. Activate the Virtual Environment

```powershell
venv\Scripts\activate
```

### 4. Install Required Libraries

```powershell
pip install pandas numpy matplotlib scikit-learn joblib streamlit
```

### 5. Run the Streamlit Application

```powershell
python -m streamlit run app.py
```

The application will open in your web browser.
